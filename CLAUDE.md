# Diese Library: SqueezeBox  

- Diese Library dient zur Anbindung von SqueezeBox-Geräten über den Lyrion Media Server, an die Software IP-Symcon. Sie stellt die notwendigen Module und Funktionen bereit, um SqueezeBox-Geräte und den Lyrion Server in IP-Symcon zu integrieren und zu steuern.
- Die Library ist so konzipiert, dass sie leicht erweiterbar ist, um fehlende Abschnitte bei der Erweiterung der Lyrion API zu ergänzen.
